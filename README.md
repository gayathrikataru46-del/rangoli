# 🐢 Python Turtle Graphics – Generative Art

A creative **generative art project built using Python's Turtle Graphics module**. The program uses loops, angles, movement, and repeated geometric patterns to create a beautiful circular abstract design.

## 🎨 Project Preview

The program generates a pattern similar to a **radial flower/mandala**, with multiple overlapping geometric curves forming a circular artwork.

## ✨ Features

* 🐢 Built using Python's `turtle` module
* 🎨 Generates abstract geometric artwork
* 🔄 Uses loops and repeated patterns
* 📐 Uses angles and turtle movement to create symmetry
* 💻 Simple beginner-friendly Python project
* 🖼️ Produces the artwork dynamically when the program runs

## 🎯 How It Works

The program controls a turtle that repeatedly moves forward and rotates by specific angles.

By repeating the same movement pattern many times while gradually changing the turtle's direction, the program creates overlapping geometric shapes.

The combination of:

```text
Movement + Rotation + Repetition
```

produces the final circular artwork.

## 📸 Output

The program produces a green radial geometric pattern with a circular empty space in the center.
